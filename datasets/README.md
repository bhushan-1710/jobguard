# Datasets

## Fake Job Posting Dataset

Source:
- Kaggle: https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction
- Dataset is an EMSCAD (Employment Scam Aegean Dataset) mirror.

To re-download:
1. Visit the Kaggle dataset page.
2. Download the CSV file.
3. Place it inside:

datasets/raw/

The raw dataset files are excluded from Git tracking.
